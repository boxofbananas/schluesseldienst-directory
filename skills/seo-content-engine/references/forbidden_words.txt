# Harte Verbotsliste der SEO-Content-Engine, deutsche Fassung. Nur die Wörter und
# Wendungen, die in keinem sichtbaren Text dieses Verzeichnisses stehen dürfen.
# lint_article.py liest diese Datei und lässt das Gate in Stufe 6 scheitern, sobald
# eines davon vorkommt; scripts/lint_copy.py liest sie zusätzlich für jeden kurzen
# Textblock (Stadttexte, Fragen, Über uns, Ratgeber).
#
# Eine Zeile je Eintrag, keine Erläuterungen in der Zeile: das Skript vergleicht
# wörtlich, also würde Prosa hier zu Falschtreffern führen.
#
# WORTSTÄMME: ein Eintrag, der auf * endet, trifft jede Fortsetzung. „lizenzier*" fängt
# „lizenziert", „lizenzierte" und „Lizenzierung"; „einzigartig*" fängt „einzigartige" und
# „einzigartigen". Deutsch beugt, deshalb stehen hier Stämme statt Grundformen: eine Liste aus
# Grundformen hat jede gebeugte Form durchgelassen. Ohne Stern gilt das ganze Wort.
#
# VIER BLÖCKE, zwei Gruppen:
#  [WORDS] / [PHRASES]  Floskeln und KI-Verräter: Werbesprache, die nichts belegt.
#                       Immer verboten, auf jeder Seite, ohne Ausnahme.
#  [RECHTSWOERTER] / [RECHTSWENDUNGEN]  die Rechts- und Amtswörter. Zwei Gründe:
#    1. RECHT: Schlüsseldienst ist in Deutschland kein zulassungspflichtiges Handwerk.
#       Es gibt keine Lizenz und keine Meisterpflicht (wiki/konventionen.md).
#    2. VERWECHSLUNG: das Wort würde den Eindruck erwecken, hinter dem Verzeichnis
#       stehe eine amtliche Stelle oder eine Standesorganisation.
#
# Nur dieser zweite Block lässt sich mit `scripts/lint_copy.py --erlaube-rechtswoerter`
# für eine einzelne Seite zulassen, und nur für /festpreis-garantie/, /premium/, /agb/ und
# Ratgeberseiten, die über die Rechtslage aufklären: dort verlangt wiki/konventionen.md ausdrücklich die Aufklärung
# („Der Schlüsseldienst ist kein zulassungspflichtiges Handwerk … wer mit ‚lizenziert‘ wirbt,
# sagt nichts aus"), und die ist ohne diese Wörter nicht zu schreiben. Für Stadttexte,
# Eintragsbeschreibungen und die Startseite gilt der Schalter nie (wiki/seo/copy-gate.md).
# Wo er nicht gilt, bleibt die Aufklärung bei den erlaubten Wörtern: „nicht
# zulassungspflichtig", „Anlage A der Handwerksordnung", „Gewerbeanmeldung", „Eintragung im
# Handelsregister".
#
# "geprüft" steht NICHT auf dieser Liste: es ist intern dem Garantie-Programm vorbehalten
# (Spalte geprueft, wiki/framework/siegel-programm.md). Dass es sonst nicht als
# allgemeines Lob auftaucht, prüft der Mensch.
#
# "Garantie" / "garantiert" (Stamm garantie*) steht im Rechtsblock, seit das Programm
# Festpreis-Garantie heißt (2026-11-03): erlaubt mit Schalter auf /festpreis-garantie/,
# /premium/ und im Garantie-Block eines Eintrags mit Garantie, den die Seite aus den Spalten
# baut. Ein Betrieb ohne Garantie darf in seiner Beschreibung nicht "garantiert" sagen, und
# auch ein Betrieb mit Garantie nicht: die Garantie zeigt die Seite, nicht sein Text.
# Der Programmname "Festpreis-Garantie" mit Bindestrich ist in lint_copy.py ausgenommen;
# die Beschreibungen (merge_enriched.py) kennen diese Ausnahme nicht.
